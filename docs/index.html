2. How to Install on Android

  1. Download app-arm64-v8a-release.apk (34.1 MB) using the button above.
  2. Open your notification shade or Files / Downloads app and tap the downloaded .apk file.
  3. If Android prompts you about unknown apps, tap Settings, enable Allow from this source for your browser or Files app, and go back.
  4. Tap Install, then open FreshKeep and allow notification permission if you want to test date reminders.

Offline & Privacy Notice

All food records, histories, and optional photos are stored strictly on your device in local SQLite storage with zero cloud upload or tracking. Date labels and storage references support meal and storage planning only and do not guarantee biological freshness.
